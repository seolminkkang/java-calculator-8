# java-calculator-precourse

## 문자열 덧셈 계산기
입력으로 주어진 문자열에서 **숫자들을 추출해 합을 계산**하는 콘솔 프로그램입니다.  
기본 구분자는 쉼표(`,`)와 콜론(`:`)이며, `"//<구분자>\n"` 형식으로 **단일 문자 커스텀 구분자**를 지정할 수 있습니다.  
빈 입력은 0을 반환하고, **양수만** 허용합니다. 규칙을 위반하면 `IllegalArgumentException`을 발생시키며 프로그램은 자연 종료합니다.  
입출력은 `camp.nextstep.edu.missionutils.Console.readLine()`을 사용합니다.

## 구현할 기능 목록
- 콘솔 입력 한 줄을 받아 결과를 `결과 : N` 형식으로 출력한다.
- 입력이 비었거나 공백뿐이면 합계 `0`을 반환한다.
- 기본 구분자 `,`, `:`를 기준으로 숫자를 분리해 합산한다.
- 입력이 `"//<구분자>\n"`로 시작하면 `<구분자>`(1글자)를 **추가 구분자**로 사용한다.
- 각 토큰은 **양의 정수**여야 하며, 비숫자/빈 토큰/`0`/음수/잘못된 커스텀 헤더는 `IllegalArgumentException`을 던진다.
- 예외 발생 시 `System.exit()` 없이 자연 종료한다. (JDK 21, 제공 라이브러리만 사용)

## 클래스별 역할
- **Application**: 프로그램 시작점. 안내 문구 출력 → `Console.readLine()`으로 입력 수신 → 계산 결과 출력. 예외는 잡되 `System.exit()` 미사용, 마지막에 `Console.close()`로 자원 정리.
- **StringAddCalculator**: 계산 흐름 총괄. 빈 입력은 0 반환, `Delimiter`로 구분자/본문 파싱 후 분리된 토큰을 `Numbers`에 위임하여 합을 반환.
- **Delimiter**: 구분자 전담. 기본 정규식(`[,:]`) 유지, `"//<구분자>\n"` 헤더를 파싱해 단일 문자 커스텀 구분자를 추가하고 최종 `split` 패턴을 구성.
- **Numbers**: 문자열 토큰을 `PositiveNumber`로 변환·보관하고 합계를 계산.
- **PositiveNumber** *(원시값 포장)*: 양의 정수만 유효한 값 객체. 생성 시 파싱·검증(비숫자/0/음수/빈 값 → 예외)을 수행하고 합산 연산을 제공.
